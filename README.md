# 📖 MangaVault — Story Research Studio

A self-hosted manga library and PDF generation web application that runs on Android using Termux.

## ✨ Features
- Smart chapter downloading
- PDF generation and stitching
- Background download queue
- Manga library management
- Dark glassmorphism interface
- Cloudflare Tunnel support

## 📱 Installation Guide

Want to host MangaVault on your own Android phone?

**[Read the Complete Installation Guide](MangaVault-SETUP-GUIDE.md)**

The guide explains how to:
- Install Termux and dependencies
- Download MangaVault from GitHub
- Initialize and start the server
- Access your website through your browser
- Use Cloudflare Tunnel for remote access

## 🛠️ Tech Stack
- Node.js + Express
- Python + Pillow
- HTML, CSS and JavaScript
- JSON storage
- Cloudflare Tunnel
